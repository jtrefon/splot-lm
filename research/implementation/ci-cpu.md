# CPU CI v0.1
GitHub-hosted ubuntu-24.04, Python 3.12.7, CPU PyTorch 2.10.0 and NumPy 1.26.4. Actions pinned to immutable release commit SHAs. Runs on PR and main push, manually dispatchable, read-only contents, no secrets, no local GPU access, no corpus or checkpoint downloads. Dependencies pinned at top level; transitive lock/hashes deferred. CPU scripts automatically discovered in tests/, tests/numerical/, tools/, tools/rep/; per-script fresh subprocess/180s timeout. All FP32/stdlib tests required; explicit unsupported BF16 CPU skips reported, not proof of BF16 validation. REP attempt structure and file hashes checked, including failed/blocked attempts; acceptance and authenticity still require human/research review. No claim of GPU parity. macOS stdlib cross-platform demo check and native CUDA qualification are separate tasks. Do not enable required check until first successful hosted run; maintainer branch protection optional after validation. Run locally in approved env: python tools/ci_cpu.py. No changes to model or experiment methodology.
