# Fixed-depth recurrent reference v0.1
2026-11-26 | #4 | [Polski — summary](recurrent-reference.pl.md)

## Scope and configuration
Implements RFC 0002's shared all-GQA dense sandwich as the next architectural control after #20. Uses the merged #19 fixture. Default executable smoke: 264 byte-vocabulary capacity, width 32, 4 Q / 2 KV heads, head dimension 8, dense SwiGLU intermediate 64, 2 prelude / 4 shared core / 2 coda blocks, R_cap=4, default R=2, I0 and S0, no depth embedding. Physical parameters 82,720; same physical count as eight untied dense blocks of the same shapes. At R=1 and I0/S0/no depth embedding, copied block weights give identical logits to the ordinary eight-layer DenseLM. At R=2 and R=4, final-only execution uses 12 and 20 block invocations respectively; all-depth coda execution uses 14 and 26. No GDN, MoE, offset-2 MTP head, exact speculative sampler, or adaptive per-token depth yet.

RecurrentConfig contains immutable DenseConfig and stage counts; base layer count must equal the physical sum. I0 none, I1 additive h+a*z, I2 convex (1-a)*h+a*z after pass 1; a=0.1/r by default. Core-only residual scale S0=1, S1=1/sqrt(2*M*R_cap), S2=0.5/(R_cap*sqrt(M)); neither depends on runtime R. Optional zero-initialized [R_cap,d] learned depth embedding before each pass, off by default. All variants are controls, not tuned stability prescriptions. No truncation/detach; actual shared core and coda gradient accumulation verified against independently unrolled copies. Checkpointing remains unimplemented. Norm/attention conventions inherited from dense reference. Only change to existing dense Block: optional scalar residual_scale=1, applied to both residual branches, preserving default semantics.

## Forward and readout interface
Input metadata as #19/#20: input_ids/document_ids/position_ids int64 and valid bool, same [B,T], same device. Forward accepts loops (1..R_cap), readouts (unique sorted requested depths, default final), use_cache, optional cache. Returns RecurrentOutput with logits dict by depth [B,T,V], pre-coda hidden dict by requested depth [B,T,d], and cache or None. The pre-coda states are exposed for future offset-2 MTP head; requesting a hidden state currently also computes its coda/NTP logits, so a cheaper hidden-only path is a future optimization. Invalid slots have zero output logits/hidden. Positions and documents handled via dense segment plan, each logical block independently observes the same causal boundaries. Full-depth NTP is target. Intermediate NTP readouts use shared coda and final norm/tied E, never distinct trained heads. Loss is the existing pre-shifted masked CE, no double shift. A0 final-only and A1 all-depth NTP are now possible; smoke uses A1 = CE_R + .25 mean earlier CE (R=1 omits earlier term). A2 offset-2 and latent losses are not implemented here.

## Logical cache contract
RecurrentCache frozen container: owner, rows, loops, readouts, ordered states keyed (stage, pass_or_readout_depth, physical_block_index). P uses depth 0; C depth 1..R; Q separate key for each requested readout. State per key is tuple of batch-row KV pairs [Hkv,L,D] (rotated K, raw V) or None. Each mutable activation cache is independent; physical weights are shared. At R=4 all readouts there are 26 logical caches; final-only has 20. Number of caches differs from physical layers=8. The current immutable-by-convention tensors are not modified in-place; retained prefix can be used for independent branches/replay. Padding skips cache update and document change replaces last-document state, inherited from dense implementation.

Cache is valid only for the same model instance, immutable weights/config, device/precision/autocast, batch row order, fixed loops and readouts. Owner, depth, selected readouts and key layout checked; weight/device/dtype changes require caller invalidation, not automatically detected. No cache during grad-enabled or training mode. Changing depth/readouts of an existing cache is deliberately rejected; shallow drafter must prefill its own state for now. Future safe shallow cache extraction may copy/reference immutable prefix state with matching coda readout or replay missing coda. No assumption of substitutable deep states. No pending logits stored inside cache; inference driver must retain them with prefix, apply EOS/stop and replay logic in future verifier. No stochastic verifier or GDN rollback tests yet.

## Validation
Run:
```bash
PYTHONPATH=src:tools python tests/test_recurrent.py
PYTHONPATH=src python tests/test_dense.py
PYTHONPATH=src:tools python tools/smoke_recurrent.py --loops 2 --steps 40
```
Seven recurrent CPU tests pass (FP64 tolerance 1e-10; training test FP32), six dense regression tests pass. Actual model checks: R1 dense equivalence and parameter count, nine injection/scale combinations with nonzero depth embeddings and prefix-depth invariance, R=1/2/4 tokenwise and irregular chunk vs full logits for all readouts and distinct KV allocations, packed-document/batch isolation/padding, nonmutating cache branch/replay and depth/readout mismatch rejection, shared core/coda gradient sums versus untied copies, finite gradients and decreasing loss on merged fixture. 40-step FP32 A1 smoke: 82,720 params, objective 6.999617 -> 3.109295, cached max absolute logit error 1.192093e-6 at both readouts. Synthetic overfit only, not comparable to earlier dense NTP loss (different objective/model/batch). See [evidence](../../experiments/results/recurrent-reference-v0.1.md).

GPU unavailable here. With reviewed commit and CUDA PyTorch, run same smoke with --device cuda, record version/GPU/driver/stdout; this is a procedure, not executed evidence. FP32 tolerances atol 1e-5 rtol 1e-4; do not widen after failed test. BF16, larger shapes, checkpointing, actual activation memory, speed and corpus training remain untested. This explicit Python-loop control is not an optimized performance baseline.
