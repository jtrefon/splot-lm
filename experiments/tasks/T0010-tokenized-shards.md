Use existing validated synthetic corpus reference and BPE artifact; construct original synthetic EN/PL prose records with explicit approved synthetic sources, duplicate families, exclusions and deterministic cluster split; prove actual train-only BPE input matches retained eligible train representatives, no quarantined or held-out inputs. Preserve original text, stable doc and cluster IDs, source revision, content digest and split; no cross-split clustering or remapping. Include BOS=1/EOS=2 only at packer boundary, PAD=0, IGNORE=-100.
