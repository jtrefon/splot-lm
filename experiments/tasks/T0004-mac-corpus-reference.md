## 2. Implementation (implementation)
Use Python standard library, immutable input records or dataclasses, type hints, clear validation errors. Provide importable functions and a small self-contained CLI/demo (no network). Document exact API in research/data/corpus-reference.md.
- Source registry: accept only explicit reviewed allowlisted source ID with nonempty immutable revision and explicit synthetic approval status; reject unknown, missing revision, pending/denied or mismatched revision. Use test-local synthetic allowlist; never edit real registry or claim actual rights. Input record requires stable unique ID, source ID/revision, group ID (globally namespaced), language (en/pl), domain (natural prose only in this first reference), UTF-8 text. Reject duplicates of record ID, invalid UTF-8/surrogate, empty text, missing/invalid metadata, >1000 records or >4096 bytes/record. Do not accept code as eligible prose. Preserve original string byte-for-byte.
- Compute raw SHA-256 and normalized fingerprint over NFC Unicode and CRLF/CR -> LF; do not change original text. No casefold/diacritic stripping for exact hashes. Union records sharing source family OR raw/normalized fingerprint. For near-duplicate reference, define Unicode whitespace-split word tokens from NFC/LF text, no stemming/casefold, 5-word shingles as tuples, set Jaccard. For two eligible documents with nonempty shingle sets union when 5*intersection >=4*union (exact integer 0.8 threshold). Shorter documents use only exact/group relations. Exhaustive all-pairs small oracle, transitive connected components across sources and languages. Stable sorted members and deterministic cluster identifier (canonical JSON of sorted stable IDs, SHA-256). Do not discard duplicate lineage.
- Quarantine all clusters containing an exact normalized fingerprint of a supplied synthetic benchmark exclusion string or explicitly excluded record ID; no fuzzy contamination claim. Select representative lexicographically smallest stable ID in each eligible cluster; document that this is deterministic not quality selection. Split clusters before output, never individual records: deterministic SHA-256 of canonical seed+cluster ID mapped to 0..99, 98/1/1 defaults and configurable percentages for tiny tests; no forced balancing or post-hoc reassignment. Record member IDs, reasons, representative, split/quarantine and fingerprint. Audit zero shared cluster IDs or normalized exact fingerprints across non-quarantined splits, all near-duplicate links within clusters, no excluded cluster in train/val/test. Stable output independent of input order; no timestamps in canonical digest. Report raw vs retained counts, language/domain/byte totals and quarantined counts. No claim of real 98/1/1 proportions from tiny fixture.
- Demo produces small JSON summary/digest for original synthetic EN/PL examples, including combining marks, diacritics, CRLF, same family, threshold edge, transitive bridges, excluded clusters. No external content; generated data explicitly synthetic.
